# Tire Match browser checks

- Landing and listed city pages: open home, follow a city link, open the city selector, and check planned cities do not imply an open service.
- Wizard location: open `/tire-match`, select a listed city, optionally enter postal code and travel preference, continue, go back, and refresh. A valid URL city follows the existing precedence rules.
- Wizard need: exercise Buy 2, Buy 4, both winter-changeover answers, repair with a description, and guidance. Repair and changeover without new tires retain the existing notice.
- Vehicle and tire size: qualifying choices show Step 3; enter a valid or invalid size, optionally add vehicle details, save, edit, refresh, and return via Back. No request is submitted. Test at mobile and desktop widths.
- Privacy: attribution remains separate and locked, and app requests remain read-only. The vendor is not loaded while entitlement and usage are unresolved.
